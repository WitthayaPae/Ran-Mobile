# Reference — decoded formats and asset knowledge

These survive the engine change. They describe the *shipped game data* and the C++ that
reads it, not any particular client implementation, so they remain accurate for the
native port.

- `ASSET-PIPELINE-AND-FORMATS.md` — the RCC extraction pipeline, the layout-probe method,
  and the rule that constants come from a probe rather than from reading a header
  (was `MOBILE/README.md`)
- `CHARACTERS.md` — how a shipped character is assembled: `.chf` → `.cps` → `.x` → clips
- `EFFECTS-SCOPE.md`, `EFFECTS-PROPS.md`, `EFFECTS-CHAR-SCOPE.md` — effect file formats,
  property layouts measured and validated against all 4,294 shipped files
- `PARITY.md` — content parity counts, generated by `tools/rcc-extract/parity-audit.js`

Current state of the port: `../STATUS.md`.
